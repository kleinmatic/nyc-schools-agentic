The Checks

What This Computer Reports

Chrome’s on-device model needs one of two things: a graphics card with more than 4 GB of video memory, or 16 GB of memory with 4 or more processor cores. It also needs 22 GB of free disk space, and Windows 10 or 11, macOS 13 or later, Linux, or a Chromebook Plus. A web page can read only part of this.

Source: Chrome for Developers, the Prompt API, read November 13, 2026.

What This Page Cannot Tell You

Chrome tells a web page only that the model is “unavailable”. It does not give the reason. So the reasons on this page are probable causes, worked out from the few hardware facts a page can read.

Chrome shows its own reason on an internal page. A link to that page does not work from a website, so copy this address into the address bar:

chrome://on-device-internals
