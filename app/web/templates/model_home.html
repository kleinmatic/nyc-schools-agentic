How This Site Works With AI Agents

The WebMCP Model Home

By Scott Klein · Updated November 10, 2026

WebMCP lets a web page tell an AI agent what it can do there. This page shows every tool it offers, lets you run each one the way an agent does, and shows what Chrome does in response.

Is Your Browser Ready?

WebMCP is an experiment in Chrome 149 and later. Where the browser does not have it, this page still works: the Run buttons call the same code and the same addresses directly.

Forms an Agent Can Fill In

Each form below is an ordinary search form with two extra attributes: a tool name and a description. Chrome turns each one into a tool. When an agent uses a form, Chrome types the values into the fields and outlines the form, so a person can see what the agent did.

These forms answer the agent in place. A person who submits one goes to the results page as usual.

Tools That Change the Page

A script can register a tool as a function. The three shortlist tools here are functions on this page: one reads the list, one adds a school, and one clears it. The list is kept in this browser tab only.

The tool that clears the list exists only while the list has schools in it. Add a school and the tool list in the next section grows by one. The clear tool is also marked as consequential, which lets a browser ask the person before an agent runs it.

    Every Tool on This Page

    This list comes from the browser, not from us: the page asks Chrome which tools it can see and prints the answer. Each Run button calls the tool through Chrome, which is the same path an agent uses.

    What the Browser Tells the Page

    Chrome sends the page an event when the tool list changes, when an agent starts a tool, and when a person cancels. The log below records each event and each tool call.

    Ask the Page

    A page can also be its own agent. This box uses the language model that Chrome runs on your computer. The model reads the tool list, picks one tool, and the page runs it and asks the model to state the result.

    The model is small and can be wrong. Check its answer against the tool result shown under it. Nothing you type here leaves your computer except the tool call to this site.

    How It Is Built

    This site is open source. Each pattern on this page is a few lines.

    Form tools
    Four HTML attributes on a form and its fields. See the forms ↗
    Answering the agent in place
    One submit handler that returns data when an agent sent the form. See the handler ↗
    Function tools
    A name, a description, the inputs, and a function. See this page ↗
    Tools that know the page
    Each school page gives an agent that school’s data and its position among similar schools. Open a school page

    Developers can see the same tool list in Chrome DevTools: open the Application panel and choose WebMCP.
