{# Opt-in chat panel, docked on the right of every page. Off by default. `?chat=on` on any URL turns it on for this browser (localStorage key `dt-chat`); `?chat=off` turns it off. The class that opens it is set by a small script in base.html's , so the page lays out at its final width before charts measure their containers. The panel is an in-page agent. It runs on Chrome's on-device model (Prompt API) and can do only what the page's WebMCP tools can do: it reads the tool list from document.modelContext.getTools() and calls executeTool(). It declares no tools of its own. Without WebMCP it falls back to the page's tool forms and their format=json endpoints. All model and tool text is written with textContent, never as HTML. #}
