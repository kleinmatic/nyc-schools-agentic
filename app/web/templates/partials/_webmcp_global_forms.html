{# Compact site-wide WebMCP-annotated forms. Included from base.html on every page EXCEPT pages that already host the same toolnames in their primary content (the homepage / and /zoned) — those override the `global_webmcp_forms` block to empty so we never duplicate a toolname within one document (WebMCP spec requires unique toolnames per page). Visible UI is intentionally small — these are an "agent-discoverable action surface for any page" first, "extra search affordance for humans" second. Keeps the page hierarchy clean while still meeting the WebMCP rule that every annotated action maps to a real human-browseable page. #}
